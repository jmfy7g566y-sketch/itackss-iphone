# itackss для iPhone

Это мобильная PWA-версия: после публикации на HTTPS её можно добавить на экран «Домой» iPhone через Safari → Поделиться → На экран «Домой».

## Что работает
- адаптивный тёмный интерфейс с пыльно-розовыми акцентами;
- быстрые переходы к Яндекс Музыке, SoundCloud, Spotify и YouTube Music;
- сохранение пользовательских ссылок в локальном хранилище браузера;
- добавление и воспроизведение локальных аудиофайлов в текущем сеансе;
- базовый офлайн-кэш интерфейса.

## Важно
- Ссылки открывают исходные сервисы; приложение не обходит подписки, авторизацию, DRM и ограничения воспроизведения.
- Локальные аудиофайлы не синхронизируются автоматически между устройствами и могут потребовать повторного выбора после закрытия браузера.
- Для постоянной установки PWA нужен HTTPS-хостинг. Самый простой вариант — GitHub Pages.
- На iPhone PWA не может гарантировать встроенное воспроизведение каждого стороннего сервиса; iOS может открыть его в Safari или приложении сервиса.

## Публикация
Загрузите содержимое этой папки в отдельный репозиторий GitHub, затем Settings → Pages → Deploy from a branch → main → /(root). После публикации откройте HTTPS-адрес в Safari на iPhone и выберите Поделиться → На экран «Домой».
